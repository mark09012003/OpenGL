# GUI 架構

主畫面採深色控制台樣式：深藍黑背景、低對比面板、青色重點線與清楚的文字層級。主視窗透明度為 97%，懸浮控制窗為 90%。Tkinter 的透明度套用於整個頂層視窗，因此面板以實色分層保持文字可讀。

- `theme.py`：顏色、字體與間距常數。
- `styles.py`：ttk 輸入框、核取方塊和選單樣式。
- `widgets.py`：可重用的面板、標籤、按鈕和文字框。
- `layout.py`：主視窗標頭、雙欄內容與事件區配置。
- `components.py`：視窗、技能、參數、操作與事件區。
- `calibration.py`：血條位置標記和座標校準。
- `window_modes.py`：懸浮控制窗、日誌窗與倒數。
- `__init__.py`：Tkinter 主控制器，保留既有設定和自動化事件流程。

背景自動化循環透過 `ui_queue` 通知主執行緒更新介面。位置標記以 Tk `after` 排程，避免從背景執行緒直接繪製元件。
