# 楓之谷 Artale 自動祈禱程式

這是一個用於楓之谷 Artale 的自動祈禱工具，包含圖形化介面，可以自動抓取遊戲視窗、調整視窗大小，並定期執行祈禱動作。

## 功能特色

- 🎮 **自動視窗管理**：自動偵測並選擇遊戲視窗
- 📐 **視窗大小調整**：可自訂視窗寬度和高度
- ⏰ **自動祈禱**：設定間隔時間自動執行祈禱
- ⌨️ **自訂按鍵**：可設定祈禱使用的按鍵
- 🖥️ **圖形化介面**：簡單易用的GUI操作介面

## 安裝需求

- Python 3.7 或更高版本
- Windows 作業系統

## 安裝步驟

1. 安裝 Python 依賴套件：
```bash
pip install -r requirements.txt
```

2. 執行程式：
```bash
python maplestory_auto_prayer.py
```

## 使用說明

1. **選擇視窗**：
   - 點擊「刷新視窗列表」按鈕更新視窗列表
   - 從列表中選擇楓之谷遊戲視窗（標有★的視窗為可能相關的視窗）
   - 點擊「選擇視窗」按鈕確認選擇

2. **設定視窗大小**（可選）：
   - 輸入想要的寬度和高度（預設：1280x720）
   - 點擊「設定視窗大小」按鈕

3. **設定祈禱參數**：
   - **祈禱按鍵**：輸入執行祈禱的按鍵（預設：F）
   - **祈禱間隔**：輸入每次祈禱之間的間隔秒數（預設：60秒）

4. **開始自動祈禱**：
   - 點擊「開始自動祈禱」按鈕
   - 程式會自動將遊戲視窗帶到前景並執行祈禱
   - 點擊「停止」按鈕可隨時停止

## 注意事項

- ⚠️ 使用自動化工具時請遵守遊戲規則
- ⚠️ 建議在安全的地方使用，避免影響遊戲體驗
- ⚠️ 程式執行時會將遊戲視窗帶到前景，請確保不會影響其他操作
- ⚠️ 如果遊戲視窗被關閉或無法找到，程式會自動停止

## 疑難排解

- **無法找到視窗**：確保遊戲正在運行，然後點擊「刷新視窗列表」
- **按鍵無效**：檢查遊戲中的按鍵設定，確保輸入的按鍵正確
- **視窗大小無法調整**：某些視窗可能被鎖定大小，請確認遊戲視窗允許調整
