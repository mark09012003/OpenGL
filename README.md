# MapleStory Artale 自動化助手

Windows 桌面程式，使用 Tkinter 控制遊戲視窗、按鍵與畫面辨識。程式會在指定的間隔執行技能，可選擇進出自由市場及定時停止。

介面採深色控制台設計。主視窗使用輕度透明，執行時可切換為較透明的懸浮控制窗；懸浮窗可拖曳並顯示下次循環倒數。

## 安裝與啟動

需求：Windows、Python 3.10 以上。

```powershell
py -m pip install -r requirements.txt
py main.py
```

打包請執行 `build.bat`。目前的 Win32 視窗控制無法在 macOS 或 Linux 執行。

## 自身血條追蹤

在介面選擇遊戲視窗後，按「測試自由市場」可查看畫面中的候選血條左端 X 座標。只有一條完整血條時可直接開始。若同時有多名角色，請把**自己的血條左端 X** 填在「自身血條 X」欄位，再按 START。座標以遊戲視窗左邊為 0，不是螢幕絕對座標。進入自由市場後若角色位置重設，也需要填入該場景中自己的血條位置；若兩場景的 X 相差很大，請先在自由市場中校準並填入，或讓畫面只出現一條血條以完成初次鎖定。

追蹤器只接受完整、寬度符合校準範圍的血條。多人血條重疊、血條被視窗邊緣裁切或候選身分不明時，程式會暫停位置判斷並放開移動鍵；它不會自動把另一條血條當成自己。若遮擋持續超過兩秒，移動流程會停止。重新開始時可更新 X 座標。

血條消失仍不是遊戲場景切換的絕對證據；離開自由市場採連續三次空畫面確認。若該場景有其他遮擋物或畫面特效，建議先用「測試自由市場」確認辨識結果。

## 專案結構

- `main.py`：啟動與依賴組裝
- `gui/__init__.py`：Tkinter 主介面、設定與執行循環
- `gui/calibration.py`、`gui/window_modes.py`：校準、位置標記與懸浮視窗
- `automation.py`：按鍵、移動與自由市場流程
- `detection.py`：截圖與畫面辨識
- `hp_tracking.py`：不依賴 GUI 的血條候選與身分追蹤
- `config.py`、`config.json`：設定與預設值

## 測試

```powershell
py -m unittest discover -s tests -v
```
